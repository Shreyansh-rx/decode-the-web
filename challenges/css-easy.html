Broken Navigation Bar

A navigation bar has incorrect spacing, alignment, colors, and positioning. Fix the CSS to match the reference design.

📋 Problem Statement

A company website has a navigation bar that looks completely wrong. The links are stacked vertically instead of horizontally, the logo is misaligned, colors are off, and the hover effects don't work. The HTML structure is correct — only the CSS needs to be fixed.

Your task is to debug and fix the CSS so the navigation bar matches the provided reference design screenshot.

✅ Requirements

  • Fix the layout so navigation links appear horizontally in a row (use Flexbox).
  • Correct the spacing between navigation items (consistent gap of 24px).
  • Align the logo to the left and links to the right.
  • Fix the background colour to a dark navy (#1e293b).
  • Make links white with a purple hover effect.
  • Fix the navbar to stay at the top of the page (sticky/fixed positioning).
  • Add smooth transition effects on hover.

🔍 How to Test & Verify Your Solution

You test your changes directly in your browser without any special tools or backend:

  1. Download Both Files: Download navbar.css and the companion index.html (available below or in the sidebar) into the same folder on your computer.
  2. Open index.html in Browser: Double-click index.html to open it in Chrome, Firefox, or Edge. You will immediately see the broken navigation bar.
  3. Edit navbar.css in VS Code: Open the folder in VS Code or any text editor. Modify the CSS properties in navbar.css and save the file (Ctrl + S).
  4. Refresh to Check: Switch back to your browser and press F5 / Ctrl + R. Your CSS changes will immediately render!
  5. Check Parity with Expected Design: Compare your browser view against the ✅ Expected Design preview above. Verify that the navbar is sticky when you scroll, links are in a single horizontal row, and hover effects work smoothly.
  6. Use Browser DevTools: Press F12 to open DevTools, select elements in the Elements tab, and verify computed padding, margins, and flexbox styles in the Computed tab.

💻 Starter Files (CSS & Companion HTML)

You will modify navbar.css. We also provide the companion index.html so you can open it in your browser to test your styles in real time.

navbar.css (file to fix) 
/* Broken Navigation CSS */

.navbar {
  /* BUG: No positioning — should be fixed */
  background-color: white; /* BUG: Should be dark navy (#1e293b) */
  padding: 0; /* BUG: Needs vertical & horizontal padding */
  /* BUG: Missing width: 100% and top: 0 */
}

.navbar-container {
  /* BUG: Not using flexbox */
  display: block;
  /* BUG: No max-width or centering */
}

.navbar-logo {
  /* BUG: No styling */
  font-size: 12px;
  color: gray;
}

.navbar-links {
  /* BUG: Links are stacking vertically */
  display: block;
  list-style: disc; /* BUG: Bullets showing */
}

.navbar-links li {
  /* BUG: Block display causing vertical stack */
  display: block;
  margin: 0; /* BUG: No spacing */
}

.navbar-links a {
  color: black; /* BUG: Wrong color — should be white */
  text-decoration: underline; /* BUG: Remove underline */
  /* BUG: Missing hover transitions */
}

/* Missing: .navbar-links a:hover, active indicators, sticky positioning */

The CSS Mystery

A complex landing page renders differently at different screen sizes. Investigate CSS specificity, conflicting selectors, and computed styles to fix it.

📋 Problem Statement

A client's landing page looks perfect in the designer's mockup, but the actual implementation has mysterious CSS issues. At desktop width it looks mostly correct, but elements shift, overlap, and disappear at different screen sizes. The CSS file contains multiple conflicting selectors, specificity wars, incorrect use of !important, inheritance issues, and broken media queries.

This is not about writing new CSS — it's about investigating existing CSS to understand why things break. You need to use the browser's Computed Styles panel, trace which selectors are winning, and fix the conflicts.

✅ Requirements

  • Investigate CSS specificity conflicts — identify which selectors are overriding intended styles and fix them.
  • Remove or fix incorrect !important declarations that are causing side effects.
  • Debug CSS inheritance issues — some child elements are inheriting colours/fonts they shouldn't.
  • Inspect computed styles in DevTools to understand what the browser is actually applying.
  • Fix overlapping elements caused by conflicting position, z-index, and transform properties.
  • Repair broken media queries that have incorrect breakpoints, conflicting rules, or are in the wrong order.
  • Ensure the page renders consistently across 320px, 768px, 1024px, and 1440px widths.

🔍 How to Test & Verify Your Solution

Use browser Developer Tools to investigate and confirm your CSS fixes:

  1. Download Both Files: Download mystery.css and the companion index.html (available below or in the sidebar) into the same folder.
  2. Open in Browser: Double-click index.html to open it in Chrome or Firefox.
  3. Inspect Specificity in DevTools: Press F12, click the Element picker, and click on the main heading. Switch to the Computed tab to see why the font color and size are overridden. In the Styles panel, look for struck-through rules and conflicting !important declarations.
  4. Edit & Fix: In VS Code, clean up the selector specificity hierarchy and fix the media query ordering in mystery.css. Save your file (Ctrl + S).
  5. Refresh & Test Responsiveness: Refresh your browser (F5) and resize the viewport. Confirm that cards display in 3 columns on desktop, 2 columns on tablet (768px), and 1 column on mobile (480px).

🔍 Investigation Tips

💡 Use the Computed Tab

In Chrome/Firefox DevTools, select an element and switch to the Computed tab. This shows you the final value of every CSS property after all specificity rules, inheritance, and cascade have been resolved. Click the arrow next to any property to see which exact rule is setting its value.

💡 Check the CSS Cascade

In the Styles panel, struck-through properties are being overridden. Check the selector specificity to understand why. Remember: inline styles > ID > class > element. !important overrides everything — but only until another !important with higher specificity appears.

💻 Starter Files (CSS & Companion HTML)

You will modify mystery.css. We also provide the companion index.html so you can open it in your browser to test your styles in real time.

mystery.css (file to fix) 
/* Conflicting specificity example */

.hero .content h1 {
  color: #1e293b;
  font-size: 3rem;
}

/* Higher specificity — overrides the above */
section.hero div.content h1.title {
  color: red !important; /* BUG: Wrong color + !important */
  font-size: 1rem; /* BUG: Way too small */
}

/* This tries to fix it but can't win */
h1 {
  color: #0f172a;
  font-size: 3.5rem;
}

/* Media query issues */
@media (max-width: 768px) {
  .features-grid {
    grid-template-columns: 1fr 1fr;
  }
}

/* BUG: This overrides the above because it comes after */
@media (max-width: 1024px) {
  .features-grid {
    grid-template-columns: 1fr; /* Should be for mobile only */
  }
}

/* Overlapping z-index chaos */
.hero { z-index: 100; position: relative; }
.nav { z-index: 50; position: fixed; } /* BUG: Nav behind hero */
.modal { z-index: 10; } /* BUG: Modal behind everything */

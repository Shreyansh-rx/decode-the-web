Interactive Counter

A webpage contains an interactive counter widget, but its buttons are broken due to event listener and state update bugs. Debug the JavaScript logic.

📋 Problem Statement

You have been given a clean counter widget intended for an interactive web dashboard. However, the developer wrote several JavaScript bugs:

Clicking the Increment button concatenates strings instead of adding numbers (e.g. producing 0111 instead of 3), clicking the Decrement button throws an unhandled reference error in the console, and the Reset button fails to update the display.

Your task is to inspect the JavaScript file, identify all syntax, scoping, and logic bugs, and restore full functionality to the counter.

✅ Requirements

  • Fix the DOM element selection so that buttons and counter display are properly targeted.
  • Ensure the counter value is stored and manipulated as a numerical Number type, preventing string concatenation.
  • Implement proper event listeners using addEventListener rather than faulty inline attributes or missing references.
  • Repair the Increment function to increase the counter by 1 on each click.
  • Repair the Decrement function to decrease the counter by 1 on each click (prevent negative values if at 0).
  • Implement the Reset function to return the counter value to 0.
  • Correctly update the DOM textContent on every action without page refresh.

🎯 Expected Behaviour

  • Initial counter displays 0.
  • Clicking + increases the value: 0 → 1 → 2 → 3.
  • Clicking − decreases the value: 3 → 2 → 1 → 0. (Stops at 0, no negative count).
  • Clicking Reset instantly sets the count back to 0.
  • No errors logged in the browser console.
  • Clean, readable vanilla JavaScript without external dependencies.

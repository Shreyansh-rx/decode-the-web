E-commerce Product Structure

An e-commerce product listing page has broken HTML elements. Your task is to fix the markup so the page renders correctly.

📋 Problem Statement

You've been given an e-commerce product listing page for an online store. The page is supposed to display a grid of product cards, each with an image, title, price, rating, and "Add to Cart" button. However, the HTML has multiple issues that cause the page to render incorrectly.

Products appear broken, images don't load, and the overall page structure doesn't match the intended design. Your task is to inspect the code and fix all the HTML issues.

✅ Requirements

  • Fix incorrectly nested elements (e.g., block elements inside inline elements, unclosed tags).
  • Correct broken image paths and add proper alt attributes for accessibility.
  • Replace generic <div> elements with semantic HTML5 elements (<article>, <section>, <header>, <main>, <nav>, <figure>).
  • Fix the product card markup — ensure each card has consistent, correctly structured HTML.
  • Ensure the document follows proper heading hierarchy (h1 → h2 → h3, no skipped levels).
  • Fix any invalid or deprecated HTML attributes.

🎯 Expected Behaviour

When correctly fixed, the product listing page should:

  • Display a structured page with a header, navigation, main content area, and footer.
  • Show 4–6 product cards in a grid layout with proper images, titles, and prices.
  • All images should load correctly with descriptive alt text.
  • The page should pass HTML validation without errors.
  • Semantic elements should be used appropriately throughout.

💻 Starter Code Preview

Below is a snippet of the broken code you'll be working with:

products.html 
<!DOCTYPE html>
<html>
<head>
  <title>TechStore - Products</title>
</head>
<body>
  <!-- BUG: No semantic header/nav elements -->
  <div class="header">
    <h1>TechStore</h1>
    <div class="nav">
      <div>Home</div>
      <div>Products</div>
      <div>Contact</div>
    </div>
  </div>

  <div class="products">
    <!-- BUG: h4 used instead of h2 (skipped levels) -->
    <h4>Featured Products</h4>

    <!-- BUG: Invalid nesting - block inside inline -->
    <span class="product-card">
      <div class="product-image">
        <!-- BUG: Broken image path, no alt -->
        <img src="images/product1">
      </div>
      <div class="product-info">
        <!-- BUG: Anchor wrapping block elements incorrectly -->
        <h5>Wireless Headphones</h5>
        <p>$59.99</p>
        <!-- BUG: Button uses div -->
        <div class="btn">Add to Cart</div>
      </div>
    </span>

    <!-- More broken product cards follow... -->
  </div>

  <div class="footer">
    <p>© 2026 TechStore</p>
  </div>
</body>
</html>

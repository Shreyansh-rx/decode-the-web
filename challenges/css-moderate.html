Dashboard Layout Repair

A dashboard interface has broken Grid and Flexbox layouts. Fix the CSS to create a properly structured, responsive dashboard.

📋 Problem Statement

You've been given a dashboard interface for an analytics application. The dashboard should display a sidebar, stat cards in a grid, a chart area, and a recent activity list. However, the CSS Grid and Flexbox properties are incorrectly configured, causing the entire layout to break.

Cards are overlapping, the sidebar is pushed below the main content, stat numbers are misaligned, and the layout completely falls apart on mobile screens. Your job is to fix all CSS issues while preserving the existing HTML structure.

✅ Requirements

  • Fix the main layout grid — sidebar on the left (250px), main content area filling the rest.
  • Correct the stat cards grid — 4 cards in a row using grid-template-columns.
  • Fix card alignment — content should be vertically centred within each card using Flexbox.
  • Repair the chart container — it should span the full width of the content area.
  • Fix the activity list — items should be properly spaced with consistent padding.
  • Add responsive breakpoints: 2 columns for tablets (768px), 1 column for mobile (480px).
  • The sidebar should collapse to a horizontal top bar on mobile.

🔍 How to Test & Verify Your Solution

Follow these steps to inspect and confirm your Grid and Flexbox repairs in real time:

  1. Download Both Files: Download dashboard.css and the companion index.html (available below or in the sidebar) into the same folder.
  2. Open in Browser: Double-click index.html to open it in Chrome or Firefox. Notice how the layout is broken with floated elements and vertical stacking.
  3. Edit in VS Code: Open dashboard.css, convert the dashboard container to display: grid, set up proper column definitions, and save (Ctrl + S).
  4. Refresh Browser: Hit F5 in your browser to verify that the sidebar and stat cards immediately form a clean multi-column grid.
  5. Test Responsive Breakpoints: Press F12 and toggle the Device Toolbar (Ctrl + Shift + M). Drag the viewport width to test:
    • Desktop (> 768px): Sidebar (250px) + Main content (1fr), 4-column stat grid.
    • Tablet (<= 768px): 2-column stat grid.
    • Mobile (<= 480px): 1-column single stacked layout with no horizontal overflow.

💻 Starter Files (CSS & Companion HTML)

You will modify dashboard.css. We also provide the companion index.html so you can open it in your browser to test your styles in real time.

dashboard.css (file to fix) 
/* Broken Dashboard Layout */

.dashboard {
  /* BUG: Not using grid */
  display: block;
}

.sidebar {
  /* BUG: Should be fixed width in grid */
  width: 100%;
  float: left; /* BUG: Don't use float */
}

.main-content {
  /* BUG: Not filling remaining space */
  width: 50%;
}

.stat-grid {
  /* BUG: Wrong grid setup */
  display: flex;
  flex-direction: column; /* BUG: Should be grid */
}

.stat-card {
  /* BUG: No flexbox alignment for content */
  text-align: left;
  padding: 0;
}

.chart-container {
  /* BUG: Width not spanning correctly */
  width: 50%;
  float: right; /* BUG: Don't use float */
}

/* BUG: No responsive breakpoints at all */

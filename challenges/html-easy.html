Registration Form Repair

A college registration website has an incorrectly structured form. Your task is to investigate the HTML and fix all structural issues.

📋 Problem Statement

You have been given a college registration form that is not working correctly. The form has several HTML issues that prevent it from functioning as intended. Users cannot submit the form properly, fields are missing labels, and the semantic structure is incorrect.

Your job is to examine the HTML source code, identify all the bugs, and fix them so the form works correctly and follows best practices.

✅ Requirements

  • Correct the overall HTML document structure (missing or misplaced tags).
  • Fix incorrect or missing input attributes (type, name, id, required, placeholder).
  • Add appropriate <label> elements with correct for attributes linked to inputs.
  • Replace non-semantic elements with correct semantic HTML (e.g., <form>, <fieldset>, <legend>).
  • Fix the form hierarchy — ensure all inputs are properly nested inside the form element.
  • Add a working submit button with the correct type attribute.

🎯 Expected Behaviour

When correctly fixed, the registration form should:

  • Display all form fields with proper labels.
  • Validate required fields before submission.
  • Use correct input types (email, tel, text, password, etc.).
  • Have a logical, accessible form structure.
  • Submit the form data when the submit button is clicked (no backend required — just correct HTML behaviour).

💻 Starter Code Preview

Below is a snippet of the broken code you'll be working with:

registration.html 
<!DOCTYPE html>
<html>
<head>
  <title>College Registration</title>
</head>
<body>
  <div class="form-container">
    <h1>Student Registration</h1>
    
    <!-- BUG: No <form> element wrapping the inputs -->
    <div class="form-group">
      <!-- BUG: Missing label elements -->
      <span>Full Name</span>
      <input type="text" placeholder="Enter name">
    </div>
    
    <div class="form-group">
      <span>Email Address</span>
      <!-- BUG: Wrong input type -->
      <input type="text" placeholder="Enter email">
    </div>
    
    <div class="form-group">
      <span>Phone Number</span>
      <!-- BUG: Wrong input type, missing attributes -->
      <input placeholder="Enter phone">
    </div>
    
    <div class="form-group">
      <span>Password</span>
      <!-- BUG: Wrong type and missing validation -->
      <input type="text" placeholder="Enter password">
    </div>

    <div class="form-group">
      <span>Course</span>
      <!-- BUG: Select element issues -->
      <input type="text" placeholder="Select course">
    </div>

    <!-- BUG: Button outside form, wrong type -->
    <div class="btn" onclick="alert('clicked')">Register</div>
  </div>
</body>
</html>
